Build a complete production-ready Invoice + Inventory + Logistics Management System as a modern full-stack web application.

1. Product

Create a multi-tenant business management platform for companies that need to manage:

- Customers
- Suppliers
- Products
- Inventory
- Warehouses
- Sales
- Invoices
- Payments
- Purchases
- Orders
- Deliveries
- Logistics
- Vehicles
- Drivers
- Expenses
- Stock transfers
- Reports
- Users and permissions

The application must be responsive and work well on desktop, tablet, and mobile.

Use a professional ERP-style UI with a clean dashboard, sidebar navigation, searchable tables, filters, forms, charts, status badges, notifications, and responsive layouts.

2. Recommended stack

Use:

- Frontend: React + TypeScript
- Framework: Vite or Next.js
- UI: Tailwind CSS + shadcn/ui
- Backend: Node.js + TypeScript
- API: REST API
- Database: PostgreSQL
- ORM: Drizzle ORM or Prisma
- Authentication: secure email/password authentication with sessions/JWT
- Validation: Zod
- Charts: Recharts
- PDF generation: server-side PDF invoices
- File storage: object storage abstraction
- Email: SMTP/provider abstraction
- Deployment: Replit

Keep the architecture modular so it can later support a mobile application and external APIs.

37. Final acceptance criteria

The finished Replit application must allow a user to perform this complete workflow:

Create customer
      ↓
Create product
      ↓
Receive product into warehouse
      ↓
Create sales order
      ↓
Reserve/pick inventory
      ↓
Generate invoice
      ↓
Record partial payment
      ↓
Create delivery
      ↓
Assign driver + vehicle
      ↓
Driver marks delivery in transit
      ↓
Driver completes delivery
      ↓
Capture proof of delivery
      ↓
Complete order
      ↓
Record remaining payment
      ↓
Update inventory
      ↓
Generate sales + inventory + logistics reports

Make this workflow fully functional end-to-end.

Build the application with clean reusable components, strong TypeScript typing, maintainable architecture, responsive UX, and production-quality error handling.

Do not stop after generating the initial scaffold. Continue implementing the features until the application is functional end-to-end and verify the main workflows with tests.
